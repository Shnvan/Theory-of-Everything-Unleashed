## One outstanding item — the two Neon orbs

The `ScientistStatues.glb` exports **three objects** so the orbs can carry Neon material while the body stays brass. On import, only the main mesh made it into Studio — the two orb sub-meshes (`Statues_TeslaOrb`, `Statues_EinsteinOrb`) were dropped. The GLB itself was re-verified after import and does contain all three objects at their expected sizes.

Almost certainly a per-sub-object checkbox in Studio's Import Preview dialog, or a "Merge Meshes" setting. To make the orbs land as separate MeshParts, the user needs to re-import `art/exhibits/ScientistStatues/build/ScientistStatues.glb` and, in the Import Preview, make sure both `Statues_TeslaOrb` and `Statues_EinsteinOrb` sub-entries are individually checked (not just the parent scene, and with **Merge Meshes off**).

**The statues exhibit was placed as a `ProductionMesh` Model** (the four-mesh black-hole pattern) rather than a bare MeshPart, precisely so the orbs can be reparented in as siblings when they arrive without disturbing anything.

Once re-imported I add both to the same Model at the same shared-origin CFrame, set `Material = Neon` with the disclosed colours (Tesla pale blue-white, Einstein warm amber), and the reposed statues finish reading as the reference composition.
