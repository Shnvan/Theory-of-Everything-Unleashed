## Composition

- **Oblate-spheroid stack of graphite layers** — the pile was not a plain rectangular box; it was flatter than a sphere with a wider waist. Rendered as 15 stacked layer-slabs whose width varies with height by a sinusoidal profile.
- Each layer split into a 3×3 block texture to hint at the machined graphite bricks below the layer scale.
- **Wooden support frame** — four corner posts + top rails, matching the real cribbed timber support.
- **Control rod** — a single horizontal rod inserted through the mid-height with a wooden handle sticking out the front.
- Base plate under the whole assembly.

## What is accurate

- **Oblate-spheroid shape**, not a plain box — CP-1's real construction.
- **15 visible layers** representing the 57-real-layer structure (each display layer stands in for roughly 4 real graphite layers).
- **Wooden framing** — the pile was built inside a square timber crib.
- **Horizontal control rod with handle** — CP-1 used cadmium sheets on wooden strips withdrawn horizontally, in contrast to modern reactors that use vertical rods.
- **Rough overall proportions** at ~1:0.21 display scale from the real 7.6 × 7.6 × 6.1 m.

## What is interpretation

- **Materials.** Real graphite is dark grey and matte; rendered in brass under D-016. Larger material gap than most exhibits.
- **Uranium is not visible.** Real bricks contained embedded uranium metal slugs and uranium oxide pseudospheres in a lattice. Not modelled — reads as pure graphite.
- **57 layers → 15 layers** is a display simplification; each display layer represents roughly 4 real layers.
- **Only one control rod shown.** Real assembly had multiple rods (safety rod ZIP, control rods).
- **No instrumentation table.** Fermi's monitoring station is not depicted.
- **Scale is 4.6 studs per real metre** — pile is smaller than half the exhibit envelope allows, but the shell width binds because the frame + base plate need to fit inside 43.20 studs.
